# 提交前检查清单

## 真实性

- [ ] 所有数据有来源（机构+报告名+年份+URL）
- [ ] 无编造的团队成员履历、合作协议、用户数据
- [ ] AI 推断内容已标注"AI推断"并请用户确认
- [ ] 政策引用有文号且为现行有效版本

## 完整性

- [ ] 赛事要求章节全部覆盖
- [ ] 执行摘要与正文结论一致
- [ ] 财务三表（利润表/现金流量表/资产负债表，如适用）齐全且有假设说明
- [ ] 附录材料齐备

## 逻辑与论证

- [ ] 每章有明确论点，论据来自主档或 research
- [ ] 竞品分析 ≥3 个主要玩家
- [ ] TAM/SAM/SOM 或等效市场测算有估算方法说明
- [ ] 无绝对化宣传词（颠覆/革命性/最优秀等）
- [ ] 全文术语统一，数据口径一致

## 格式

- [ ] 按学校/赛事模板核对栏目顺序、字号、页边距
- [ ] 图表有编号、题注、正文引用
- [ ] 页数/字数符合要求
- [ ] 文档可正常打开，字体已嵌入或使用通用字体

## 查重与合规

- [ ] 查重率符合要求（通常 <30%，以赛事通知为准）
- [ ] 图片均有版权来源或为原创
- [ ] 无未授权引用
- [ ] 涉及个人信息/商业机密的材料已脱敏

## 评审视角终审

- [ ] 评委能在 5 分钟内看懂项目做什么、为什么做、怎么赚钱/产生价值
- [ ] 路演稿与 PPT 页码对应，讲稿时长在限时内
- [ ] 答辩 Q&A 覆盖最可能被追问的 20 题
