# 赛事适配矩阵

写作前确认目标赛事，按对应评审侧重调整结构、篇幅与材料。赛事规则每年可能调整，正式写作前以当年官方通知为准。

## 各赛事总览

| 赛事 | 材料形态 | 评审侧重 | 常见扣分点 |
|---|---|---|---|
| 大创 · 创新训练项目 | 申报书 | 创新性、可行性、研究方案、预期成果 | 立项依据空泛、工作量不足 |
| 大创 · 创业训练/实践 | 申报书+商业计划 | 市场需求、商业模式、落地可行性 | 财务不实、团队能力不匹配 |
| 挑战杯 · 课外学术科技作品 | 学术论文/作品报告 | 研究方法、原创性、学术规范 | 文献综述薄弱、结论与数据不匹配 |
| 挑战杯 · 创业计划（小挑） | 商业计划书 | 社会价值、商业逻辑、实践验证 | 社会价值空喊、无实践验证 |
| 互联网+/中国国际大学生创新大赛 | 商业计划书+路演 | 教育、创新、团队、商业、社会价值 | 路演超时、数据来源不明、团队分工不清 |
| 三创赛 | 商业计划书 | 商业模式创新、运营数据 | 套模板、无运营数据 |
| 创青春 | 创业计划书 | 市场、财务、落地 | 财务预测无假设 |

## 分赛事写法侧重

### 大创

- 申报书重"为什么做、怎么做、能做到什么"：立项依据、国内外现状、研究/实施内容、进度安排、预期成果、经费预算。
- 创新训练强调研究方案与技术路线；创业训练/实践强调市场验证与商业闭环。
- 严格按学校模板，注意栏目顺序、字数与格式。

### 挑战杯

- 学术类：问题提出 → 文献综述 → 研究设计 → 数据/实验 → 结论，重方法严谨与引用规范。
- 创业类：突出社会价值量化（覆盖人群、就业、产业带动），商业模式要可推演。

### 互联网+/中国国际大学生创新大赛

- 五个评审维度：教育维度（育人故事、课程/实践结合）、创新维度（技术/模式/组织创新）、团队维度（能力与分工）、商业维度（市场、财务、可持续）、社会价值维度（解决真实问题、带动就业）。
- 路演通常 5-8 分钟：一页一观点，PPT 服务演讲节奏；答辩准备 20-30 个问题。
- 数据必须带来源，政策带文号。

### 三创赛/商赛

- 强调数据化运营：用户量、转化率、GMV、成本结构。
- 商业模式画布要完整：价值主张、客户细分、渠道、收入、成本、关键资源/活动/伙伴。

## 通用材料清单

- 商业计划书/申报书正文（按赛事章节要求）
- 一页纸摘要（执行摘要）
- 路演 PPT（含演讲备注）
- 路演稿（5/8 分钟版本）
- 答辩 Q&A 清单（20-30 题）
- 附录：团队简历、专利/软著、合作意向、财务报表、调研问卷
