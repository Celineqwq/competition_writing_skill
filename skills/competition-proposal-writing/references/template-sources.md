# 公开申报模板来源

> 更新日期：2026-09-05
> 用途：用户说“使用现有申报模板/网上找模板”时，先从这里选择公开来源；任何模板都不得默认适用于当前赛事，必须先按当年官方通知/命题页校验。

## 默认输出规则

若无说明需要填写申报表，则只需要填写申报书（项目计划书/作品材料），不要因为本文件列了模板就默认要求用户提供申报表。

## 使用顺序

1. 用户已提供模板：直接解析模板，不得用本文件中的示例模板覆盖用户表格。
2. 用户未提供模板且目标赛事为“中国国际大学生创新大赛·产业命题赛道”：先在命题详情页确认作品提交内容；公开 GitHub 未检索到全国统一空白申报书模板，学校或赛区附件才可能是正式契约。
3. 用户未提供模板且目标赛事为高校大创（创新训练/创业训练/创业实践）：可使用下方公开模板了解常见栏目结构，但最终以用户所在学校当年通知和空白表为准。

## 产业命题赛道的模板边界

- 中国国际大学生创新大赛产业命题赛道的正式约束通常来自命题详情页的“命题内容及答题要求”和“作品提交内容”，不是某份全国统一 Word 申报书。
- 如果用户把命题详情文本当作选题要求，仍必须单独找学校/赛区当年的报名附件；找不到时在正文标注“待学校模板确认”，不得把往年或其他学校模板当作正式申报表。
